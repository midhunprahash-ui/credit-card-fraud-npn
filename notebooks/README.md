# Notebooks

All notebooks used by the team are inside `notebooks/lightning_ai/`.

Start with `00_shared_data_preparation.ipynb`, then run the notebook assigned
to your model team. The simple instructions are in
[the teammate training guide](../docs/TEAMMATE_TRAINING_GUIDE.md). A
browser-friendly HTML export may be kept
locally, but it is intentionally ignored by Git.

Version 2 is separate and starts at
[`lightning_ai/v2/10_v2_behavioral_data_preparation.ipynb`](lightning_ai/v2/10_v2_behavioral_data_preparation.ipynb).
See [`lightning_ai/v2/README.md`](lightning_ai/v2/README.md) before running it.
